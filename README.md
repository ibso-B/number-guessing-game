# Number Guessing Game 🎯

A beginner-friendly number guessing game built with Python.

## Description

The computer randomly selects a number between 1 and 100. The player tries to guess the secret number and receives hints indicating whether each guess is too high or too low.

The game counts the number of valid guesses and allows the player to play multiple rounds.

## Features

- Random number generation
- High and low hints
- Attempt counter
- Input validation
- Replay option

## Requirements

- Python 3.10 or newer

## How to Run

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Run the following command:

   ```bash
   python guessing_game.py
   ```

4. Follow the instructions displayed in the terminal.
